# qualgate 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 저장소를 컨테이너에서 스캔해 규칙 위반, 중복도, 커버리지를 판정하고 결과를 Gitea 이슈로 동기화하는 Rust CLI를 만든다.

**Architecture:** Rust 바이너리 하나가 Opengrep 릴리스 바이너리를 외부 프로세스로 실행하고, 중복 탐지와 커버리지 파싱은 직접 수행한다. `scan`은 네트워크 없이 `/out/result.json`을 쓰고, `publish`는 코드를 읽지 않고 그 파일만으로 Gitea 이슈를 동기화한다. 상태는 이슈 본문의 숨은 주석에 저장한다.

**Tech Stack:** Rust(edition 2021), clap, serde, serde_json, toml, anyhow, quick-xml, ureq, rayon, walkdir, globset, sha2, tempfile, tree-sitter 및 언어 문법 크레이트, Opengrep v1.33.1, Alpine, Docker

**Spec:** `docs/superpowers/specs/2026-11-06-qualgate-design.md` (Task 1에서 `C:\workspace\sonarqube\docs\superpowers\specs\`에서 복사)

## Global Constraints

- 프로젝트 위치: `C:\workspace\qualgate`. 라이선스: LGPL-3.0.
- 지원 언어: Java, Kotlin, Python, React(JSX/TSX), Vue, Go.
- 출처: `SonarSource/sonarqube` 공개 소스(LGPL 3)만 참고·포팅한다. 포팅 파일에 원본 저작권 고지를 유지한다. Sonar Enterprise, SSAL 분석기, 디컴파일 결과는 사용하지 않는다. `semgrep-rules`, `opengrep-rules`를 저장소에 넣지 않는다.
- 로컬에 Rust가 없으므로 빌드와 테스트는 항상 `scripts/cargo.sh`(Docker)로 실행한다.
- 종료 코드: `0` 게이트 통과, `1` 게이트 실패, `2` 실행 오류.
- 토큰은 환경 변수 `GITEA_TOKEN`으로만 받고 로그에 출력하지 않는다.
- 측정하지 못한 값은 0이 아니라 `None`(측정 안 됨)으로 다룬다.
- 분석 실패 파일의 이슈는 절대 닫지 않는다.
- 크레이트 API 이름은 작성 시점 문서 기준이다. 컴파일 오류가 나면 동작을 바꾸지 않는 범위에서 해당 버전의 API에 맞춘다. 원격 push는 사용자가 요청할 때만 한다.

```rust
#[derive(Debug, Clone, Copy, PartialEq, Eq, PartialOrd, Ord, Serialize, Deserialize)]
#[serde(rename_all = "lowercase")]
pub enum Severity { Info, Low, Medium, High, Critical }

impl Severity {
    pub fn parse(s: &str) -> Option<Severity> {
        match s.to_ascii_lowercase().as_str() {
            "info" => Some(Severity::Info),
            "low" => Some(Severity::Low),
            "medium" => Some(Severity::Medium),
            "high" => Some(Severity::High),
            "critical" => Some(Severity::Critical),
            _ => None,
        }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Eq, Hash)]
pub enum Lang { Java, Kotlin, Python, Js, Ts, Tsx, Go, Vue }

impl Lang {
    pub fn of(path: &str) -> Option<Lang> {
        let ext = path.rsplit('.').next()?.to_ascii_lowercase();
        Some(match ext.as_str() {
            "java" => Lang::Java,
            "kt" | "kts" => Lang::Kotlin,
            "py" => Lang::Python,
            "js" | "jsx" | "mjs" | "cjs" => Lang::Js,
            "ts" | "mts" | "cts" => Lang::Ts,
            "tsx" => Lang::Tsx,
            "go" => Lang::Go,
            "vue" => Lang::Vue,
            _ => return None,
        })
    }
    /// 복제 탐지에서 서로 비교할 언어 묶음
    pub fn dup_group(self) -> &'static str {
        match self {
            Lang::Java => "java",
            Lang::Kotlin => "kotlin",
            Lang::Python => "python",
            Lang::Go => "go",
            Lang::Js | Lang::Ts | Lang::Tsx | Lang::Vue => "web",
        }
    }
}

pub fn line_hash(line: &str) -> String {
    let compact: String = line.chars().filter(|c| !c.is_whitespace()).collect();
    let digest = Sha256::digest(compact.as_bytes());
    digest.iter().map(|b| format!("{b:02x}")).collect()
}
```

```rust
use anyhow::Result;
use globset::{Glob, GlobBuilder, GlobSet, GlobSetBuilder};
use std::path::Path;
use walkdir::WalkDir;

/// root 아래 파일을 `/` 구분 상대 경로로 정렬해 반환한다. `.git`은 제외한다.
pub fn walk(root: &Path) -> Vec<String> {
    let mut out: Vec<String> = WalkDir::new(root)
        .into_iter()
        .filter_entry(|e| e.file_name() != ".git")
        .filter_map(|e| e.ok())
        .filter(|e| e.file_type().is_file())
        .filter_map(|e| e.path().strip_prefix(root).ok().map(|p| p.to_string_lossy().replace('\\', "/")))
        .collect();
    out.sort();
    out
}

pub fn globset(patterns: &[String]) -> Result<GlobSet> {
    let mut b = GlobSetBuilder::new();
    for p in patterns {
        let g: Glob = GlobBuilder::new(p).literal_separator(true).build()?;
        b.add(g);
    }
    Ok(b.build()?)
}

#[cfg(test)]

        std::fs::create_dir_all(d.path().join("a")).unwrap();
        std::fs::write(d.path().join(".git/x"), "").unwrap();
        std::fs::write(d.path().join("a/b.go"), "").unwrap();
```

```rust
#[cfg(test)]
mod grammars {
    use tree_sitter::{Language, Parser};

    fn parses(lang: Language, src: &str) {
        let mut p = Parser::new();
        p.set_language(&lang).unwrap();
        let t = p.parse(src, None).unwrap();
```

```rust
pub fn extract(src: &str) -> Option<Extracted> {
    let mut keep: Vec<(usize, usize)> = Vec::new();
    let mut ts = false;
    let mut pos = 0;
    while pos < src.len() {
        let rest = &src[pos..];
        let next_t = rest.find("<template");
        let next_s = rest.find("<script");
        match (next_t, next_s) {
            (None, None) => break,
            (Some(t), s) if s.map_or(true, |s| t < s) => {
                pos = skip_template(src, pos + t);
            }
            (_, Some(s)) => {
                let tag_start = pos + s;
                let open_end = tag_start + src[tag_start..].find('>')? + 1;
                let tag = &src[tag_start..open_end];
                if tag.contains("lang=\"ts\"") || tag.contains("lang='ts'") || tag.contains("lang=\"tsx\"") { ts = true; }
                let close = open_end + src[open_end..].find("</script>")?;
                keep.push((open_end, close));
                pos = close + "</script>".len();
            }
            (Some(_), None) => unreachable!(),
        }
    }
    if keep.is_empty() { return None; }
    let mut text = String::with_capacity(src.len());
    for (i, ch) in src.char_indices() {
        let inside = keep.iter().any(|(a, b)| i >= *a && i < *b);
        if inside || ch == '\n' || ch == '\r' { text.push(ch); } else { text.push(' '); }
    }
    Some(Extracted { text, ext: if ts { "ts" } else { "js" } })
}

fn skip_template(src: &str, start: usize) -> usize {
    let mut depth = 0usize;
    let mut pos = start;
    loop {
        let rest = &src[pos..];
        let open = rest.find("<template");
        let close = rest.find("</template>");
        match (open, close) {
            (Some(o), Some(c)) if o < c => { depth += 1; pos += o + "<template".len(); }
            (_, Some(c)) => {
                depth = depth.saturating_sub(1);
                pos += c + "</template>".len();
                if depth == 0 { return pos; }
            }
            _ => return src.len(),
        }
    }
}
```

```rust
#[derive(Deserialize)]
struct Output { #[serde(default)] results: Vec<RawResult>, #[serde(default)] errors: Vec<RawError> }
#[derive(Deserialize)]
struct RawResult { check_id: String, path: String, start: Pos, extra: Extra }
#[derive(Deserialize)]
struct Pos { line: u32 }
#[derive(Deserialize)]
struct Extra {
    #[serde(default)] message: String,
    #[serde(default)] severity: String,
    #[serde(default)] metadata: serde_json::Value,
}
#[derive(Deserialize)]
struct RawError { #[serde(default)] path: Option<String> }

fn clean(p: &str) -> String { p.trim_start_matches("./").replace('\\', "/") }

fn fallback_severity(s: &str) -> Severity {
    match s.to_ascii_uppercase().as_str() {
        "ERROR" => Severity::High,
        "WARNING" => Severity::Medium,
        _ => Severity::Low,
    }
}

pub fn parse_output(json: &str, disabled: &[String], read_line: &dyn Fn(&str, u32) -> Option<String>) -> Result<RulesOutcome> {
    let out: Output = serde_json::from_str(json).context("Opengrep JSON 파싱 실패")?;
    let mut res = RulesOutcome::default();
    for r in out.results {
        let meta = |k: &str| r.extra.metadata.get(k).and_then(|v| v.as_str()).map(str::to_string);
        let rule = meta("qualgate_id").unwrap_or_else(|| r.check_id.clone());
        if disabled.contains(&rule) { continue; }
        let severity = meta("qualgate_severity").and_then(|s| Severity::parse(&s))
            .unwrap_or_else(|| fallback_severity(&r.extra.severity));
        let category = meta("qualgate_category").unwrap_or_else(|| "external".into());
        let file = clean(&r.path);
        let line_text = read_line(&file, r.start.line).unwrap_or_default();
        res.findings.push(Finding {
            rule, line: r.start.line, line_hash: line_hash(&line_text),
            message: r.extra.message.clone(), severity, category, file,
        });
    }
    for e in out.errors {
        if let Some(p) = e.path { res.unanalyzed.push(clean(&p)); }
    }
    res.unanalyzed.sort();
    res.unanalyzed.dedup();
    Ok(res)
}

fn invoke(opts: &RunOpts, target: &Path, exclude: &[String]) -> Result<String> {
    let out_dir = tempfile::tempdir()?;
    let out_file = out_dir.path().join("o.json");
    let mut c = Command::new(&opts.opengrep);
    c.current_dir(target).arg("scan").arg(format!("--json-output={}", out_file.display()));
    for r in &opts.rule_paths { c.arg("-f").arg(r); }
    for e in exclude { c.arg("--exclude").arg(e); }
    c.arg(".");
    let o = c.output().with_context(|| format!("{} 실행 실패", opts.opengrep))?;
    if !o.status.success() {
        bail!("Opengrep 실패 ({}): {}", o.status, String::from_utf8_lossy(&o.stderr));
    }
    std::fs::read_to_string(&out_file).context("Opengrep 결과 파일 없음")
}

fn line_at(text: &str, line: u32) -> Option<String> {
    text.lines().nth(line.checked_sub(1)? as usize).map(str::to_string)
}

pub fn run(opts: &RunOpts) -> Result<RulesOutcome> {
    let excl = crate::fsutil::globset(&opts.exclude)?;
    let src = opts.src.clone();
    let read_src = move |f: &str, l: u32| std::fs::read_to_string(src.join(f)).ok().and_then(|t| line_at(&t, l));
    let json = invoke(opts, &opts.src, &opts.exclude)?;
    let mut all = parse_output(&json, &opts.disabled, &read_src)?;
    all.findings.retain(|f| !excl.is_match(&f.file));
    all.unanalyzed.retain(|f| !excl.is_match(f));

    // Vue: script만 남긴 임시 파일을 `<경로>.vue.<ext>`로 만들어 별도 스캔
    let tmp = tempfile::tempdir()?;
    let mut any_vue = false;
    for rel in crate::fsutil::walk(&opts.src) {
        if !rel.ends_with(".vue") || excl.is_match(&rel) { continue; }
        let Ok(text) = std::fs::read_to_string(opts.src.join(&rel)) else {
            all.unanalyzed.push(rel);
            continue;
        };
        if let Some(e) = crate::vue::extract(&text) {
            let dst = tmp.path().join(format!("{rel}.{}", e.ext));
            std::fs::create_dir_all(dst.parent().unwrap())?;
            std::fs::write(dst, e.text)?;
            any_vue = true;
        }
    }
    if any_vue {
        let strip = |f: &str| f.rsplit_once(".vue.").map(|(a, _)| format!("{a}.vue")).unwrap_or_else(|| f.to_string());
        let src2 = opts.src.clone();
        let read_vue = move |f: &str, l: u32| std::fs::read_to_string(src2.join(strip(f))).ok().and_then(|t| line_at(&t, l));
        let json = invoke(opts, tmp.path(), &[])?;
        let v = parse_output(&json, &opts.disabled, &read_vue)?;
        for mut f in v.findings { f.file = strip(&f.file); all.findings.push(f); }
        for f in v.unanalyzed { all.unanalyzed.push(strip(&f)); }
    }
    all.unanalyzed.sort();
    all.unanalyzed.dedup();
    Ok(all)
}
```

```rust
    for lang in ["java", "kotlin", "python", "react", "vue", "go"] {
        let dir = root.join(lang);
        let n_before = v.len();
        for e in std::fs::read_dir(&dir).unwrap_or_else(|_| panic!("{} 없음", dir.display())) {
            let p = e.unwrap().path();
            if p.extension().is_some_and(|x| x == "yaml") { v.push(p); }
        }
        assert!(v.len() - n_before >= 20, "{lang} 규칙이 20개 미만");
    }
    v
}

fn scan(rule: &Path, file: &Path) -> serde_json::Value {
    let out = tempfile::NamedTempFile::new().unwrap();
    let dir = file.parent().unwrap();
    let st = Command::new("opengrep")
        .current_dir(dir)
        .args(["scan", "--no-git-ignore"])
        .arg(format!("--json-output={}", out.path().display()))
        .arg("-f").arg(rule)
        .arg(file.file_name().unwrap())
        .output().unwrap();
    assert!(st.status.success(), "{}: {}", rule.display(), String::from_utf8_lossy(&st.stderr));
    serde_json::from_str(&std::fs::read_to_string(out.path()).unwrap()).unwrap()
}
```

```rust
    e.attributes().flatten().find(|a| a.key.as_ref() == name)
        .map(|a| String::from_utf8_lossy(&a.value).into_owned())
}

fn merge_line(m: &mut BTreeMap<u32, LineCov>, line: u32, c: LineCov) {
    let e = m.entry(line).or_default();
    e.covered |= c.covered;
    e.conditions = e.conditions.max(c.conditions);
    e.covered_conditions = e.covered_conditions.max(c.covered_conditions);
}

pub fn parse_jacoco(xml: &str) -> Result<RawCov> {
    let mut r = Reader::from_str(xml);
    let mut out = RawCov::new();
    let (mut pkg, mut file) = (String::new(), None::<String>);
    loop {
        match r.read_event().context("JaCoCo XML 오류")? {
            Event::Start(e) | Event::Empty(e) => match e.name().as_ref() {
                b"package" => pkg = attr(&e, b"name").unwrap_or_default(),
                b"sourcefile" => {
                    let n = attr(&e, b"name").unwrap_or_default();
                    file = Some(if pkg.is_empty() { n } else { format!("{pkg}/{n}") });
                }
                b"line" => if let Some(f) = &file {
                    let g = |k: &[u8]| attr(&e, k).and_then(|v| v.parse::<u32>().ok()).unwrap_or(0);
                    let (mb, cb) = (g(b"mb"), g(b"cb"));
                    merge_line(out.entry(f.clone()).or_default(), g(b"nr"),
                        LineCov { covered: g(b"ci") > 0, conditions: mb + cb, covered_conditions: cb });
                },
                _ => {}
            },
            Event::End(e) if e.name().as_ref() == b"sourcefile" => file = None,
            Event::Eof => break,
            _ => {}
        }
    }
    Ok(out)
}

pub fn parse_cobertura(xml: &str) -> Result<RawCov> {
    let mut r = Reader::from_str(xml);
    let mut out = RawCov::new();
    let mut file = None::<String>;
    let mut saw_root = false;
    loop {
        match r.read_event().context("Cobertura XML 오류")? {
            Event::Start(e) | Event::Empty(e) => match e.name().as_ref() {
                b"coverage" => saw_root = true,
                b"class" => file = attr(&e, b"filename"),
                b"line" => if let Some(f) = &file {
                    let line = attr(&e, b"number").and_then(|v| v.parse().ok()).unwrap_or(0);
                    let hits: u64 = attr(&e, b"hits").and_then(|v| v.parse().ok()).unwrap_or(0);
                    let (cc, total) = attr(&e, b"condition-coverage").as_deref().and_then(parse_condition).unwrap_or((0, 0));
                    merge_line(out.entry(f.clone()).or_default(), line,
                        LineCov { covered: hits > 0, conditions: total, covered_conditions: cc });
                },
                _ => {}
            },
            Event::End(e) if e.name().as_ref() == b"class" => file = None,
            Event::Eof => break,
            _ => {}
        }
    }
    anyhow::ensure!(saw_root, "Cobertura 루트 요소 없음");
    Ok(out)
}

fn parse_condition(s: &str) -> Option<(u32, u32)> {
    let inner = s.split('(').nth(1)?.trim_end_matches(')');
    let (a, b) = inner.split_once('/')?;
    Some((a.trim().parse().ok()?, b.trim().parse().ok()?))
}

pub fn parse_lcov(text: &str) -> Result<RawCov> {
    let mut out = RawCov::new();
    let mut file = None::<String>;
    let mut branches: BTreeMap<u32, (u32, u32)> = BTreeMap::new();
    for line in text.lines() {
        if let Some(p) = line.strip_prefix("SF:") {
            file = Some(p.trim().replace('\\', "/"));
            branches.clear();
        } else if let Some(p) = line.strip_prefix("DA:") {
            let f = file.as_ref().context("LCOV: SF 없는 DA")?;
            let (n, c) = p.split_once(',').context("LCOV: DA 형식")?;
            let hits: u64 = c.split(',').next().unwrap_or("0").parse().unwrap_or(0);
            merge_line(out.entry(f.clone()).or_default(), n.parse().context("LCOV: 줄 번호")?,
                LineCov { covered: hits > 0, ..Default::default() });
        } else if let Some(p) = line.strip_prefix("BRDA:") {
            let parts: Vec<&str> = p.split(',').collect();
            anyhow::ensure!(parts.len() == 4, "LCOV: BRDA 형식");
            let n: u32 = parts[0].parse().context("LCOV: 줄 번호")?;
            let taken = parts[3] != "-" && parts[3] != "0";
            let e = branches.entry(n).or_default();
            e.0 += 1;
            if taken { e.1 += 1; }
        } else if line.trim() == "end_of_record" {
            if let Some(f) = &file {
                for (n, (t, c)) in &branches {
                    merge_line(out.entry(f.clone()).or_default(), *n,
                        LineCov { covered: false, conditions: *t, covered_conditions: *c });
                }
            }
            file = None;
            branches.clear();
        }
    }
    Ok(out)
}

pub fn parse_go(text: &str) -> Result<RawCov> {
    let mut out = RawCov::new();
    for line in text.lines() {
        if line.starts_with("mode:") || line.trim().is_empty() { continue; }
        let (file, rest) = line.rsplit_once(':').context("Go 커버리지 형식")?;
        let mut it = rest.split_whitespace();
        let range = it.next().context("Go: 범위 없음")?;
        let _stmts = it.next().context("Go: 문장 수 없음")?;
        let count: u64 = it.next().context("Go: 횟수 없음")?.parse().context("Go: 횟수")?;
        let (a, b) = range.split_once(',').context("Go: 범위 형식")?;
        let sl: u32 = a.split('.').next().unwrap_or("0").parse().context("Go: 시작 줄")?;
        let el: u32 = b.split('.').next().unwrap_or("0").parse().context("Go: 끝 줄")?;
        for n in sl..=el {
            merge_line(out.entry(file.to_string()).or_default(), n,
                LineCov { covered: count > 0, ..Default::default() });
        }
    }
    Ok(out)
}

/// 리포트 경로와 저장소 경로를 뒤에서부터 비교해 가장 길게 일치하는 파일을 고른다.
pub fn resolve(report_path: &str, files: &[String]) -> Option<String> {
    let rp: Vec<&str> = report_path.split('/').filter(|s| !s.is_empty()).collect();
    let mut best = 0usize;
    let mut found: Vec<&String> = vec![];
    for f in files {
        let n = f.split('/').rev().zip(rp.iter().rev()).take_while(|(a, b)| a == *b).count();
        if n == 0 { continue; }
        if n > best { best = n; found = vec![f]; } else if n == best { found.push(f); }
    }
    if found.len() == 1 { Some(found[0].clone()) } else { None }
}

pub fn load(src: &Path, files: &[String], cfg: &CoverageCfg) -> Loaded {
    let mut out = Loaded::default();
    let all = crate::fsutil::walk(src);
    let kinds: [(&Vec<String>, fn(&str) -> Result<RawCov>); 4] = [
        (&cfg.jacoco, parse_jacoco), (&cfg.cobertura, parse_cobertura),
        (&cfg.lcov, parse_lcov), (&cfg.go, parse_go),
    ];
    for (patterns, parser) in kinds {
        let Ok(gs) = crate::fsutil::globset(patterns) else { out.errors.extend(patterns.iter().cloned()); continue };
        for rel in all.iter().filter(|p| gs.is_match(p.as_str())) {
            let parsed = std::fs::read_to_string(src.join(rel)).map_err(anyhow::Error::from).and_then(|t| parser(&t));
            match parsed {
                Err(_) => out.errors.push(rel.clone()),
                Ok(raw) => {
                    out.reports.push(rel.clone());
                    for (path, lines) in raw {
                        match resolve(&path, files) {
                            None => out.unresolved.push(path),
                            Some(f) => {
                                let dst = out.map.entry(f).or_default();
                                for (n, c) in lines { merge_line(dst, n, c); }
                            }
                        }
                    }
                }
            }
        }
    }
    for v in [&mut out.reports, &mut out.unresolved, &mut out.errors] { v.sort(); v.dedup(); }
    out
}
```

```rust
pub fn parse_diff(diff: &str) -> ChangedLines {
    let mut out = ChangedLines::new();
    let mut file: Option<String> = None;
    for line in diff.lines() {
        if let Some(p) = line.strip_prefix("+++ ") {
            file = p.strip_prefix("b/").map(str::to_string);
        } else if line.starts_with("@@") {
            let Some(f) = &file else { continue };
            let Some(plus) = line.split_whitespace().find(|t| t.starts_with('+')) else { continue };
            let spec = plus.trim_start_matches('+');
            let (start, count) = match spec.split_once(',') {
                Some((a, b)) => (a.parse::<u32>().unwrap_or(0), b.parse::<u32>().unwrap_or(0)),
                None => (spec.parse::<u32>().unwrap_or(0), 1),
            };
            let e = out.entry(f.clone()).or_default();
            for n in start..start.saturating_add(count) { e.insert(n); }
        }
    }
    out
}

pub fn changed(src: &Path, days: u32) -> Result<Option<ChangedLines>> {
    if git(src, &["rev-parse", "--is-shallow-repository"])?.trim() == "true" { return Ok(None); }
    let before = format!("--before={days} days ago");
    let base = git(src, &["rev-list", "-1", &before, "HEAD"])?;
    let base = base.trim();
    if base.is_empty() { return Ok(None); }
    let diff = git(src, &["diff", "-U0", base, "HEAD"])?;
    Ok(Some(parse_diff(&diff)))
}

pub fn head_info(src: &Path) -> Result<(String, Option<String>)> {
    let commit = git(src, &["rev-parse", "HEAD"])?.trim().to_string();
    if let Ok(b) = std::env::var("QUALGATE_BRANCH") {
        if !b.is_empty() { return Ok((commit, Some(b))); }
    }
    let branch = git(src, &["rev-parse", "--abbrev-ref", "HEAD"])?.trim().to_string();
    Ok((commit, if branch == "HEAD" { None } else { Some(branch) }))
}
```

```rust
pub fn coverage_pct(map: &CoverageMap, only: Option<&ChangedLines>) -> Option<f64> {
    let (mut total, mut covered) = (0u64, 0u64);
    for (file, lines) in map {
        for (n, c) in lines {
            if let Some(ch) = only {
                if !ch.get(file).is_some_and(|s| s.contains(n)) { continue; }
            }
            total += 1 + c.conditions as u64;
            covered += c.covered as u64 + c.covered_conditions as u64;
        }
    }
    (total > 0).then(|| 100.0 * covered as f64 / total as f64)
}

fn dup_lines(clones: &[CloneGroup]) -> BTreeMap<&str, BTreeSet<u32>> {
    let mut m: BTreeMap<&str, BTreeSet<u32>> = BTreeMap::new();
    for g in clones {
        for p in &g.parts {
            m.entry(p.file.as_str()).or_default().extend(p.start_line..=p.end_line);
        }
    }
    m
}

pub fn duplication(clones: &[CloneGroup], total_lines: &BTreeMap<String, u32>, only: Option<&ChangedLines>) -> Option<f64> {
    let dups = dup_lines(clones);
    let (mut total, mut dup) = (0u64, 0u64);
    match only {
        None => {
            total = total_lines.values().map(|v| *v as u64).sum();
            dup = dups.iter().filter(|(f, _)| total_lines.contains_key(**f)).map(|(_, s)| s.len() as u64).sum();
        }
        Some(ch) => for (f, lines) in ch {
            if !total_lines.contains_key(f) { continue; }
            total += lines.len() as u64;
            if let Some(s) = dups.get(f.as_str()) { dup += lines.intersection(s).count() as u64; }
        },
    }
    (total > 0).then(|| 100.0 * dup as f64 / total as f64)
}

pub fn blocking_on_changed(findings: &[Finding], changed: Option<&ChangedLines>, severities: &[String]) -> Option<u64> {
    let ch = changed?;
    let blocking: Vec<Severity> = severities.iter().filter_map(|s| Severity::parse(s)).collect();
    Some(findings.iter().filter(|f| blocking.contains(&f.severity) && ch.get(&f.file).is_some_and(|s| s.contains(&f.line))).count() as u64)
}

pub fn evaluate(cfg: &GateCfg, m: &Metrics, coverage_required_missing: bool) -> GateResult {
    let min = |name: &str, a: Option<f64>, limit: f64, force_fail: bool| Condition {
        name: name.into(), actual: a, limit,
        status: match a {
            _ if force_fail => ConditionStatus::Failed,
            None => ConditionStatus::Skipped,
            Some(v) if v >= limit => ConditionStatus::Passed,
            Some(_) => ConditionStatus::Failed,
        },
    };
    let max = |name: &str, a: Option<f64>, limit: f64| Condition {
        name: name.into(), actual: a, limit,
        status: match a {
            None => ConditionStatus::Skipped,
            Some(v) if v <= limit => ConditionStatus::Passed,
            Some(_) => ConditionStatus::Failed,
        },
    };
    let conditions = vec![
        min("new_coverage", m.new_coverage, cfg.new_coverage_min, coverage_required_missing),
        max("new_duplication", m.new_duplication, cfg.new_duplication_max),
        max("new_blocking", m.new_blocking.map(|v| v as f64), cfg.new_blocking_max as f64),
    ];
    GateResult { passed: conditions.iter().all(|c| c.status != ConditionStatus::Failed), conditions }
}
```

```rust
fn language(lang: Lang) -> Language {
    match lang {
        Lang::Java => tree_sitter_java::LANGUAGE.into(),
        Lang::Kotlin => tree_sitter_kotlin_ng::LANGUAGE.into(),
        Lang::Python => tree_sitter_python::LANGUAGE.into(),
        Lang::Js => tree_sitter_javascript::LANGUAGE.into(),
        Lang::Ts | Lang::Vue => tree_sitter_typescript::LANGUAGE_TYPESCRIPT.into(),
        Lang::Tsx => tree_sitter_typescript::LANGUAGE_TSX.into(),
        Lang::Go => tree_sitter_go::LANGUAGE.into(),
    }
}

fn skip_node(n: &Node) -> bool {
    let k = n.kind();
    k.contains("comment") || (n.child_count() > 0 && (k.contains("import") || k.contains("package")))
}

fn collect<'a>(n: Node<'a>, src: &[u8], out: &mut BTreeMap<u32, (u64, u32)>) {
    if skip_node(&n) { return; }
    if n.child_count() == 0 {
        if n.end_byte() == n.start_byte() { return; }
        let line = n.start_position().row as u32 + 1;
        let e = out.entry(line).or_insert((0xcbf29ce484222325, 0));
        for b in &src[n.start_byte()..n.end_byte()] {
            e.0 ^= *b as u64;
            e.0 = e.0.wrapping_mul(0x100000001b3);
        }
        e.0 ^= 0xff;
        e.0 = e.0.wrapping_mul(0x100000001b3);
        e.1 += 1;
        return;
    }
    let mut c = n.walk();
    for child in n.children(&mut c) { collect(child, src, out); }
}

pub fn tokenize(lang: Lang, src: &str) -> Option<Vec<TokenLine>> {
    let (text, grammar) = if lang == Lang::Vue {
        let e = crate::vue::extract(src)?;
        let g = if e.ext == "ts" { Lang::Ts } else { Lang::Js };
        (e.text, g)
    } else {
        (src.to_string(), lang)
    };
    let mut p = Parser::new();
    p.set_language(&language(grammar)).ok()?;
    let tree = p.parse(&text, None)?;
    let mut m = BTreeMap::new();
    collect(tree.root_node(), text.as_bytes(), &mut m);
    Some(m.into_iter().map(|(line, (hash, tokens))| TokenLine { line, hash, tokens }).collect())
}

struct FileBlocks { file: String, lines: Vec<TokenLine>, hashes: Vec<u64> }

/// `PmdBlockChunker`: 같은 줄이 연속되면 처음과 마지막만 남기고 롤링 해시로 블록을 만든다.
fn chunk(lines: Vec<TokenLine>, block: usize) -> (Vec<TokenLine>, Vec<u64>) {
    let mut f: Vec<TokenLine> = Vec::with_capacity(lines.len());
    let mut i = 0;
    while i < lines.len() {
        let mut j = i + 1;
        while j < lines.len() && lines[j].hash == lines[i].hash { j += 1; }
        f.push(lines[i].clone());
        if i < j - 1 { f.push(lines[j - 1].clone()); }
        i = j;
    }
    if block == 0 || f.len() < block { return (f, vec![]); }
    let mut hashes = Vec::with_capacity(f.len() - block + 1);
    let mut power = 1u64;
    for _ in 0..block - 1 { power = power.wrapping_mul(31); }
    let mut h = 0u64;
    for t in &f[..block] { h = h.wrapping_mul(31).wrapping_add(t.hash); }
    hashes.push(h);
    for k in block..f.len() {
        h = h.wrapping_sub(f[k - block].hash.wrapping_mul(power));
        h = h.wrapping_mul(31).wrapping_add(f[k].hash);
        hashes.push(h);
    }
    (f, hashes)
}

const MAX_OCCURRENCES: usize = 200;

fn detect_group(files: &[FileBlocks], cfg: &DupCfg) -> Vec<CloneGroup> {
    let mut index: HashMap<u64, Vec<(usize, usize)>> = HashMap::new();
    for (fi, f) in files.iter().enumerate() {
        for (bi, h) in f.hashes.iter().enumerate() { index.entry(*h).or_default().push((fi, bi)); }
    }
    let part = |fi: usize, start: usize, run: usize| -> (ClonePart, u64) {
        let f = &files[fi];
        let end = start + run - 1 + cfg.block_lines - 1;
        let tokens: u64 = f.lines[start..=end].iter().map(|t| t.tokens as u64).sum();
        (ClonePart { file: f.file.clone(), start_line: f.lines[start].line, end_line: f.lines[end].line }, tokens)
    };
    let mut groups: BTreeMap<String, BTreeSet<ClonePart>> = BTreeMap::new();
    for occ in index.values() {
        if occ.len() < 2 || occ.len() > MAX_OCCURRENCES { continue; }
        for (x, &(fa, ba)) in occ.iter().enumerate() {
            for &(fb, bb) in &occ[x + 1..] {
                let same_prev = ba > 0 && bb > 0 && files[fa].hashes[ba - 1] == files[fb].hashes[bb - 1];
                if same_prev { continue; }
                let mut run = 1;
                while ba + run < files[fa].hashes.len() && bb + run < files[fb].hashes.len()
                    && files[fa].hashes[ba + run] == files[fb].hashes[bb + run] { run += 1; }
                let (pa, ta) = part(fa, ba, run);
                let (pb, tb) = part(fb, bb, run);
                if ta.min(tb) < cfg.min_tokens as u64 { continue; }
                if fa == fb && pa.end_line >= pb.start_line && pb.end_line >= pa.start_line { continue; }
                let mut sha = Sha256::new();
                for h in &files[fa].hashes[ba..ba + run] { sha.update(h.to_le_bytes()); }
                let key: String = sha.finalize().iter().map(|b| format!("{b:02x}")).collect();
                let e = groups.entry(key).or_default();
                e.insert(pa);
                e.insert(pb);
            }
        }
    }
    groups.into_iter().map(|(key, parts)| {
        let parts: Vec<ClonePart> = parts.into_iter().collect();
        let lines = parts.iter().map(|p| p.end_line - p.start_line + 1).max().unwrap_or(0);
        CloneGroup { key, parts, lines }
    }).collect()
}

pub fn detect(root: &Path, files: &[String], cfg: &DupCfg) -> DupOutcome {
    enum R { Ok(String, Lang, u32, Vec<TokenLine>), Bad(String) }
    let results: Vec<R> = files.par_iter().filter_map(|rel| {
        let lang = Lang::of(rel)?;
        let Ok(text) = std::fs::read_to_string(root.join(rel)) else { return Some(R::Bad(rel.clone())); };
        match tokenize(lang, &text) {
            Some(t) => Some(R::Ok(rel.clone(), lang, text.lines().count() as u32, t)),
            None if lang == Lang::Vue => Some(R::Ok(rel.clone(), lang, text.lines().count() as u32, vec![])),
            None => Some(R::Bad(rel.clone())),
        }
    }).collect();
    let mut out = DupOutcome::default();
    let mut by_group: BTreeMap<&'static str, Vec<FileBlocks>> = BTreeMap::new();
    for r in results {
        match r {
            R::Bad(f) => out.unanalyzed.push(f),
            R::Ok(file, lang, n, lines) => {
                out.total_lines.insert(file.clone(), n);
                let (lines, hashes) = chunk(lines, cfg.block_lines);
                by_group.entry(lang.dup_group()).or_default().push(FileBlocks { file, lines, hashes });
            }
        }
    }
    for files in by_group.values() { out.clones.extend(detect_group(files, cfg)); }
    out.clones.sort_by(|a, b| b.lines.cmp(&a.lines).then(a.key.cmp(&b.key)));
    out.unanalyzed.sort();
    out
}
```

```rust
/// `Tracker.trackNonClosed`의 매칭 순서. 원본 3번(블록 코드 이동 감지)은 1차에서 제외한다.
fn stage_key(stage: u8, it: &Item) -> String {
    let (r, l, h, m) = (&it.rule, it.line, &it.line_hash, &it.message);
    match stage {
        1 => format!("{r}\0{l}\0{h}\0{m}"),
        2 => format!("{r}\0{l}\0{h}"),
        3 => format!("{r}\0{h}\0{m}"),
        4 => format!("{r}\0{l}\0{m}"),
        _ => format!("{r}\0{h}"),
    }
}

pub fn track(raw: &[Item], base: &[Item]) -> Tracking {
    let mut raw_done = vec![false; raw.len()];
    let mut base_done = vec![false; base.len()];
    let mut matched = Vec::new();
    for stage in 1..=5u8 {
        let mut index: HashMap<String, Vec<usize>> = HashMap::new();
        for (bi, b) in base.iter().enumerate().rev() {
            if !base_done[bi] { index.entry(stage_key(stage, b)).or_default().push(bi); }
        }
        for (ri, r) in raw.iter().enumerate() {
            if raw_done[ri] { continue; }
            if let Some(bi) = index.get_mut(&stage_key(stage, r)).and_then(|v| v.pop()) {
                raw_done[ri] = true;
                base_done[bi] = true;
                matched.push((ri, bi));
            }
        }
    }
    Tracking {
        matched,
        new_items: raw_done.iter().enumerate().filter(|(_, d)| !**d).map(|(i, _)| i).collect(),
        gone: base_done.iter().enumerate().filter(|(_, d)| !**d).map(|(i, _)| i).collect(),
    }
}
```

```rust
    let json = serde_json::to_string(st).expect("상태 직렬화");
    // JSON 안의 `-->`가 HTML 주석을 닫지 않도록 이스케이프한다.

pub fn parse_state(body: &str) -> Option<IssueState> {
    let start = body.rfind(MARK)? + MARK.len();
    let end = start + body[start..].find(" -->")?;
```

```rust
use anyhow::{bail, Context};
use serde::Deserialize;
use serde_json::{json, Value};
use std::time::Duration;
use ureq::tls::{RootCerts, TlsConfig};

pub struct Client { agent: ureq::Agent, base: String, repo: String, token: String }

#[derive(Deserialize)]
struct LabelDto { id: u64, name: String }
#[derive(Deserialize)]
struct IssueDto { number: u64, title: String, #[serde(default)] body: Option<String>, state: String, #[serde(default)] labels: Vec<LabelDto> }

impl Client {
    pub fn new(base: &str, repo: &str, token: &str) -> Client {
        let agent: ureq::Agent = ureq::Agent::config_builder()
            .http_status_as_error(false)
            .timeout_global(Some(Duration::from_secs(60)))
            .tls_config(TlsConfig::builder().root_certs(RootCerts::PlatformVerifier).build())
            .build()
            .into();
        Client { agent, base: base.trim_end_matches('/').to_string(), repo: repo.to_string(), token: token.to_string() }
    }

    fn url(&self, path: &str) -> String { format!("{}/api/v1/repos/{}{}", self.base, self.repo, path) }

    fn call(&self, method: &str, url: &str, body: Option<&Value>) -> Result<Value> {
        let mut last = String::new();
        for attempt in 0..4 {
            if attempt > 0 { std::thread::sleep(Duration::from_secs(1 << attempt)); }
            let auth = format!("token {}", self.token);
            let resp = match (method, body) {
                ("GET", _) => self.agent.get(url).header("Authorization", &auth).call(),
                ("POST", Some(b)) => self.agent.post(url).header("Authorization", &auth).send_json(b),
                ("PATCH", Some(b)) => self.agent.patch(url).header("Authorization", &auth).send_json(b),
                _ => bail!("지원하지 않는 호출 {method}"),
            };
            let mut resp = match resp {
                Ok(r) => r,
                Err(e) => { last = e.to_string(); continue; }
            };
            let code = resp.status().as_u16();
            let text = resp.body_mut().read_to_string().unwrap_or_default();
            match code {
                200..=299 => return if text.trim().is_empty() { Ok(Value::Null) } else { serde_json::from_str(&text).context("Gitea 응답 파싱") },
                401 | 403 => bail!("Gitea 권한 오류 ({code}). 토큰에 write:issue와 저장소 읽기 권한이 필요합니다."),
                429 | 500..=599 => { last = format!("HTTP {code}"); continue; }
                _ => bail!("Gitea 오류 {code}: {method} {url}: {text}"),
            }
        }
        bail!("Gitea 호출 재시도 실패: {method} {url}: {last}")
    }

    fn label_ids(&mut self, names: &[String]) -> Result<Vec<u64>> {
        let all: Vec<LabelDto> = serde_json::from_value(self.call("GET", &self.url("/labels?limit=50"), None)?)?;
        Ok(all.into_iter().filter(|l| names.contains(&l.name)).map(|l| l.id).collect())
    }
}

impl IssueApi for Client {
    fn default_branch(&mut self) -> Result<String> {
        let v = self.call("GET", &format!("{}/api/v1/repos/{}", self.base, self.repo), None)?;
        v["default_branch"].as_str().map(str::to_string).context("default_branch 없음")
    }

    fn ensure_label(&mut self, name: &str) -> Result<()> {
        if self.label_ids(&[name.to_string()])?.is_empty() {
            self.call("POST", &self.url("/labels"), Some(&json!({"name": name, "color": "#ee8800"})))?;
        }
        Ok(())
    }

    fn list_issues(&mut self, label: &str) -> Result<Vec<Issue>> {
        let mut out = vec![];
        for page in 1.. {
            let url = self.url(&format!("/issues?state=all&type=issues&labels={label}&limit=50&page={page}"));
            let rows: Vec<IssueDto> = serde_json::from_value(self.call("GET", &url, None)?)?;
            if rows.is_empty() { break; }
            out.extend(rows.into_iter().map(|d| Issue {
                number: d.number, title: d.title, body: d.body.unwrap_or_default(),
                open: d.state == "open", labels: d.labels.into_iter().map(|l| l.name).collect(),
            }));
        }
        Ok(out)
    }

    fn create_issue(&mut self, title: &str, body: &str, labels: &[String]) -> Result<u64> {
        let ids = self.label_ids(labels)?;
        let v = self.call("POST", &self.url("/issues"), Some(&json!({"title": title, "body": body, "labels": ids})))?;
        v["number"].as_u64().context("생성된 이슈 번호 없음")
    }

    fn edit_issue(&mut self, number: u64, title: &str, body: &str, open: bool) -> Result<()> {
        let state = if open { "open" } else { "closed" };
        self.call("PATCH", &self.url(&format!("/issues/{number}")), Some(&json!({"title": title, "body": body, "state": state})))?;
        Ok(())
    }

    fn comment(&mut self, number: u64, body: &str) -> Result<()> {
        self.call("POST", &self.url(&format!("/issues/{number}/comments")), Some(&json!({"body": body})))?;
        Ok(())
    }
}
```

```rust
use crate::config::Config;
use crate::model::*;
use crate::{coverage, dup, fsutil, gate, newcode, rules};
use anyhow::Result;
use std::path::Path;

pub fn scan(src: &Path, rules_root: &Path, opengrep: &str) -> Result<ScanResult> {
    let cfg = Config::load(src)?;
    let (commit, branch) = newcode::head_info(src)?;
    let exclude = fsutil::globset(&cfg.scan.exclude)?;
    let tests = fsutil::globset(&cfg.scan.test_paths)?;
    let all = fsutil::walk(src);
    let code: Vec<String> = all.iter().filter(|p| Lang::of(p).is_some() && !exclude.is_match(p.as_str())).cloned().collect();
    let prod: Vec<String> = code.iter().filter(|p| !tests.is_match(p.as_str())).cloned().collect();

    let mut rule_paths = vec![rules_root.to_path_buf()];
    rule_paths.extend(cfg.rules.extra_paths.iter().map(|p| src.join(p)));
    let outcome = rules::run(&rules::RunOpts {
        opengrep: opengrep.to_string(),
        src: src.to_path_buf(),
        rule_paths,
        exclude: cfg.scan.exclude.clone(),
        disabled: cfg.rules.disabled.clone(),
    })?;

    let d = dup::detect(src, &prod, &cfg.duplication);
    let loaded = coverage::load(src, &code, &cfg.coverage);
    for e in &loaded.errors { eprintln!("경고: 커버리지 리포트를 읽지 못했습니다: {e}"); }

    let changed = match newcode::changed(src, cfg.new_code.days) {
        Ok(c) => c,
        Err(e) => { eprintln!("경고: 신규 코드를 계산하지 못했습니다: {e:#}"); None }
    };
    let has_cov = !loaded.reports.is_empty();
    let metrics = Metrics {
        coverage: gate::coverage_pct(&loaded.map, None),
        new_coverage: changed.as_ref().filter(|_| has_cov).and_then(|c| gate::coverage_pct(&loaded.map, Some(c))),
        duplication: gate::duplication(&d.clones, &d.total_lines, None),
        new_duplication: changed.as_ref().and_then(|c| gate::duplication(&d.clones, &d.total_lines, Some(c))),
        new_blocking: gate::blocking_on_changed(&outcome.findings, changed.as_ref(), &cfg.gate.blocking_severities),
    };
    let required_missing = cfg.coverage.required && !has_cov;
    let gate_result = gate::evaluate(&cfg.gate, &metrics, required_missing);

    let not_in_report: Vec<String> = if has_cov {
        prod.iter().filter(|p| !loaded.map.contains_key(p.as_str())).cloned().collect()
    } else { vec![] };
    let mut unanalyzed = outcome.unanalyzed;
    unanalyzed.extend(d.unanalyzed);
    unanalyzed.sort();
    unanalyzed.dedup();

    Ok(ScanResult {
        schema: 1, commit, branch,
        findings: outcome.findings,
        clones: d.clones,
        metrics,
        coverage_status: CoverageStatus { reports: loaded.reports, unresolved: loaded.unresolved, not_in_report },
        gate: gate_result,
        unanalyzed,
        publish: PublishConfig { max_new_issues: cfg.publish.max_new_issues, labels: cfg.publish.labels },
    })
}
```

```rust
use anyhow::{Context, Result};
use clap::{Parser, Subcommand};
use qualgate::gitea::{Client, IssueApi};
use qualgate::model::ScanResult;
use std::path::{Path, PathBuf};

#[derive(Parser)]
#[command(version, about = "코드 품질을 스캔해 Gitea 이슈로 동기화합니다")]
struct Cli { #[command(subcommand)] cmd: Cmd }

#[derive(Subcommand)]
enum Cmd {
    /// 코드를 스캔해 result.json을 씁니다. 네트워크가 필요 없습니다.
    Scan {
        #[arg(long, default_value = "/src")] src: PathBuf,
        #[arg(long, default_value = "/out")] out: PathBuf,
    },
    /// result.json을 Gitea 이슈에 반영합니다. 코드를 읽지 않습니다.
    Publish {
        #[arg(long)] repo: String,
        #[arg(long, default_value = "/out")] out: PathBuf,
    },
    /// scan과 publish를 차례로 실행합니다.
    Run {
        #[arg(long)] repo: String,
        #[arg(long, default_value = "/src")] src: PathBuf,
        #[arg(long, default_value = "/out")] out: PathBuf,
    },
}

fn do_scan(src: &Path, out: &Path) -> Result<ScanResult> {
    let file = out.join("result.json");
    if file.exists() { std::fs::remove_file(&file).context("이전 결과 삭제 실패")?; }
    let rules = std::env::var("QUALGATE_RULES").unwrap_or_else(|_| "/rules".into());
    let og = std::env::var("QUALGATE_OPENGREP").unwrap_or_else(|_| "opengrep".into());
    let r = qualgate::scan::scan(src, Path::new(&rules), &og)?;
    std::fs::create_dir_all(out)?;
    std::fs::write(&file, serde_json::to_vec_pretty(&r)?).context("결과 파일 쓰기 실패")?;
    println!("위반 {}건, 중복 그룹 {}개, 게이트 {}", r.findings.len(), r.clones.len(), if r.gate.passed { "통과" } else { "실패" });
    Ok(r)
}

fn do_publish(r: &ScanResult, repo: &str) -> Result<()> {
    let base = std::env::var("GITEA_URL").context("GITEA_URL 환경 변수가 필요합니다")?;
    let token = std::env::var("GITEA_TOKEN").context("GITEA_TOKEN 환경 변수가 필요합니다")?;
    let mut api = Client::new(&base, repo, &token);
    let default = api.default_branch()?;
    if r.branch.as_deref() != Some(default.as_str()) {
        println!("브랜치 {:?}는 기본 브랜치 {default}가 아니어서 이슈를 동기화하지 않습니다.", r.branch);
        return Ok(());
    }
    let rep = qualgate::sync::sync(&mut api, r, base.trim_end_matches('/'), repo)?;
    println!("이슈 생성 {}, 갱신 {}, 종료 {}, 재오픈 {}, 제한으로 보류 {}", rep.created, rep.updated, rep.closed, rep.reopened, rep.skipped);
    Ok(())
}

fn load_result(out: &Path) -> Result<ScanResult> {
    let t = std::fs::read_to_string(out.join("result.json")).context("result.json이 없습니다. scan이 성공했는지 확인하세요")?;
    serde_json::from_str(&t).context("result.json 형식 오류")
}

fn run(cli: Cli) -> Result<ScanResult> {
    match cli.cmd {
        Cmd::Scan { src, out } => do_scan(&src, &out),
        Cmd::Publish { repo, out } => { let r = load_result(&out)?; do_publish(&r, &repo)?; Ok(r) }
        Cmd::Run { repo, src, out } => { let r = do_scan(&src, &out)?; do_publish(&r, &repo)?; Ok(r) }
    }
}

fn main() {
    match run(Cli::parse()) {
        Ok(r) => std::process::exit(if r.gate.passed { 0 } else { 1 }),
        Err(e) => { eprintln!("오류: {e:#}"); std::process::exit(2); }
    }
}
```

```yaml
name: qualgate
on:
  push:
    branches: [main]
  schedule:
    - cron: "0 18 * * *"
jobs:
  qualgate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
        with:
          fetch-depth: 0
      # 프로젝트의 테스트를 실행해 커버리지 리포트를 만드는 단계를 여기 둔다.
      - name: scan
        run: |
          mkdir -p .qualgate-out && chmod 777 .qualgate-out
          docker run --rm --network none -e QUALGATE_BRANCH="${{ github.ref_name }}" \
            -v "$PWD:/src:ro" -v "$PWD/.qualgate-out:/out" registry.example.com/qualgate:latest scan
      - name: publish
        if: always()
        run: |
          docker run --rm -v "$PWD/.qualgate-out:/out:ro" \
            -e GITEA_URL="${{ github.server_url }}" -e GITEA_TOKEN="${{ secrets.QUALGATE_TOKEN }}" \
            registry.example.com/qualgate:latest publish --repo "${{ github.repository }}"
```
